# SAPV Friedland · DE / EN / PL

Frameworkfreie Azure Static Web App mit drei Sprachfassungen, responsive Design, Teamfotos, FAQ, Karrierebereich, Einzugsgebiet, Rechtsseiten und erweitertem Feedbackformular.

## Azure Build
- app_location: `/`
- api_location: leer
- output_location: leer

## Wichtig
Die interne Datei `VOR_VEROEFFENTLICHUNG_CHECKLISTE.md` vollständig abarbeiten. Impressum, Datenschutz, Übersetzungen, Teamdaten und Einwilligungen vor dem Livegang fachlich beziehungsweise rechtlich prüfen.

Das Feedbackformular öffnet das E-Mail-Programm des Nutzers. Es überträgt nicht selbständig Daten an einen Server.
